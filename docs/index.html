送健保「事前審查」前,先自己對一次答案。

台灣健保有些藥品和治療,醫療院所要先送「事前審查(TWPAS)」才給付。 這個開源專案幫你把申請自動組成健保系統看得懂的國際標準格式(FHIR),並在送出前 用健保自己公開的規則先檢查一遍 —— 該補的先補、會被退錢的先擋。

它解決什麼問題?

申請填錯或漏填,健保收件當下看起來沒事 —— 但問題不是當下爆,是幾週後審查才「核刪」(把已經給你的錢扣回去)。

「送出去沒事」是陷阱。這個工具在送出前, 用健保官方規則先跑一遍,把那些「事後才會爆」的問題提前抓出來,讓你先修再送。

它做的五件事

① 產組申請 — 把病人、醫師、診斷(ICD)、要申請的藥…組成一份標準 FHIR 文件(Bundle),保證通過官方驗證 0 錯誤。
② 驗基本檢查 — 藥和適應症是不是合法組合。
③ 查送前自查 — 用健保官方 CQL 規則對這份申請跑一遍,得出三態: 通過會被核刪缺資料待補
④ 送提交 — 送到收件端。
⑤ 回核定回應 — 收到結果。注意:「受理」不等於「核准」,真正核定是事後才有。
